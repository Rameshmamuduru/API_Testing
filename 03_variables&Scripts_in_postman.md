## Variables and Scripts in Postman:

are like a placeholder to holds the values.

**Types of Variables**

- Global Variables **[Accessble eveywhere]**
- Environment variables **[applicable for specific environment]**
- collection varibales **[Specific to the collection only]**
- local variables **[Specific to single request]**
- data Variables **[values provided through json/csv files in the collection runner]** [can be used in API chaining]

**Types of Scripts**
1. pre-request scripts
2. post-response scripts

**These are available at three levels**
1. collection level
2. folder level
3. request level


## API Chaining

Allow us to execute the multiple API requests in sequence where the output from one API used as the input for another/susequent API.
